## Long (company profile)

SvGrid is the enterprise-grade data grid for Svelte: the complete, professional,
performance-first grid that serious applications can standardize on, brought
native to the Svelte ecosystem.

It is built by jQWidgets, an independent software company that has specialized in
high-performance UI components since 2011. The company's first product,
jQWidgets, anchored by the jqxGrid data grid, set a principle that still defines
the team: a grid is a performance product first. Components that stutter when a
user scrolls, sorts, or filters do not survive in real enterprise software, so
virtualization, stable references, and minimal repaints are designed in from the
start rather than bolted on later.

As the web platform matured, the team rebuilt its suite on web standards and
launched it as Smart UI on htmlelements.com, letting a single component run across
React, Angular, Vue, and plain HTML. Across both generations of products,
jQWidgets and Smart UI components have been used in enterprise software at
companies including Samsung, Boeing, NVIDIA, Microsoft, Nokia, and Intel, among
thousands of organizations worldwide. Smart UI was voted Gold Winner among
software development service providers in Visual Studio Magazine's 2025 Readers'
Choice Awards.

SvGrid is the team's native grid for Svelte 5. Rather than wrap an engine designed
for another framework, it was written from scratch to exploit Svelte's
fine-grained reactivity, and built for an AI-native future in which assistants are
first-class consumers of the library. The goal is straightforward: to be the
default, enterprise-ready data grid for Svelte, the standard a serious Svelte
application can build on. The company is led by founder Boyko Markov and is the
same team that has shipped grids for over a decade.

## Why SvGrid

- **Category standard.** Built to be the default data grid a serious Svelte
  application standardizes on, the role a professional grid plays in every mature
  ecosystem.
- **Enterprise depth.** Sorting, filtering, grouping, pivoting, editing, export,
  and virtualization at the depth enterprise applications actually require.
- **Native, not a wrapper.** Written for Svelte 5 runes, not bridged from another
  framework's engine.
- **Proven lineage.** Fifteen years of grid engineering behind it, not a first
  attempt.
