Data validation: an Input Message shown under the selected cell, and
Circle Invalid Data.

The dialog's third tab gives a rule a title and message, kept on the rule
as `input` and saved with the document. Data Validation is now Excel's
menu: the dialog, Circle Invalid Data (a red oval on every cell under a
rule whose contents break it, worked out again on each repaint) and Clear
Validation Circles. `invalidCells` is the check on its own. The shell also
gains `act(action)`, which runs a ribbon action as its button would.
